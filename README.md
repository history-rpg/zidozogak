# 지도 조각 대모험

6학년 사회 세계 지리 단원을 포켓몬형 픽셀 RPG로 만든 게임입니다. 외계인에게서 세계지도 조각을 되찾으며 세계 여러 지역의 자연환경과 생활 모습을 탐험합니다.

- 게임: https://history-rpg.github.io/zidozogak/
- 만든 이: 박봉두 선생님, siu김

## 폴더
- `index.html` — 게임 한 장 (빌드 결과)
- `worker/` — 전국 랭킹·이용 현황 창구 (Cloudflare Worker + D1). 개인 정보(이름·학교)는 받지 않습니다.
- `rank-url.txt` — 랭킹 창구 주소 (배포 때 자동으로 적힘)
